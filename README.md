# Deal Hunter AI

Amazon・楽天市場・Yahoo!ショッピングなどの価格と過去相場を比較し、明らかに安い商品を見つけるアプリです。

## v0.1.0

- スマホ向けダークUI
- 家電・ゲーム・ホビーの絞り込み
- AIスコア／値引率／価格で並び替え
- 商品詳細とサイト別価格比較
- お気に入りを端末内に保存
- PWA対応
- GitHub Pages自動デプロイ

現在の商品・価格データはUI検証用サンプルです。次の段階で正規APIを接続し、実データ取得・価格履歴保存・同一商品照合を追加します。

## ロードマップ

1. 楽天・Yahoo!の正規API接続
2. JANコード・型番を使った商品照合
3. PostgreSQLへの価格履歴保存
4. 他サイト中央値＋過去30日平均との差によるスコアリング
5. 値下がり通知とお気に入り監視
